## Sequence Names in Actions/Sequences UI (ID + Name)

### Summary
Add profile-scoped sequence names (max 16 chars), editable from the Sequences page, and display them in sequence selectors as `1 (Name)` (or `1` if empty).  
Scope includes:
1. Actions tab sequence dropdowns.
2. Sequences tab nested sequence dropdowns (when a step sends `Sequence`).
3. Sequences tab selector buttons and current sequence title.

### Public Interface Changes
- Add runtime storage: `sequenceNames[SEQUENCES][17]` (16 chars + null terminator), default empty.
- Add config schema field: top-level `SequenceNames` array (20 items), each item:
1. `Sequence` (`1..20`)
2. `Name` (string, `maxLength: 16`)
- Add NVS profile key: `SeqNames` (`putBytes/getBytes` for full array).
- Add Sequences form field: `sequencename` (text input, `maxlength=16`).

### Implementation Changes
- Data model and defaults:
1. Introduce `MAXSEQUENCENAME 16`.
2. Add `sequenceNames` global array.
3. Initialize all names to empty in factory/default initialization.
- Persistence and compatibility:
1. On profile save, persist names to NVS (`SeqNames`) and config export (`SequenceNames`) when sequences are included.
2. On profile load, read names from NVS key if present; if missing/size mismatch, keep all names empty.
3. On config import, read optional `SequenceNames`; if absent, keep defaults; truncate oversized names via `strlcpy`.
4. Keep old configs fully compatible (existing `Sequences` rows still load unchanged).
- Web UI behavior:
1. In `/sequences`, add a header-level text input bound to current selected sequence name (`sequencename`).
2. In `POST /sequences`, update only the current sequence’s name from `sequencename` before apply/save handling.
3. Render sequence labels with helper logic:
1. If name is empty: `N`
2. If name exists: `N (Name)`
4. Apply that label format to:
1. Actions tab `sequence` dropdown options.
2. Sequences tab step-level `sequence` dropdown options.
3. Sequences tab top selector buttons.
4. Sequences tab card title (`Sequence N (Name)` when present).

### Test Plan
1. Edit sequence 3 name to `Verse`, click Apply: UI immediately shows `3 (Verse)` in Actions/Sequences selectors and Sequences header/buttons.
2. Save and reboot: names persist for the active profile.
3. Switch profiles A/B/C: each profile has independent sequence names.
4. Export config with sequences: `SequenceNames` is present and correct.
5. Import that config: names restore exactly.
6. Import legacy config without `SequenceNames`: no errors, labels fall back to numeric-only.
7. Validate long input handling: >16 chars is truncated safely and does not break rendering.
8. Smoke-check sequence-triggering behavior unchanged (runtime uses existing numeric sequence IDs only).

### Assumptions
- Sequence names are metadata only and do not affect runtime sequence execution logic.
- Empty name means numeric-only label (`N`), not autogenerated text.
- Names are ASCII-safe text input using existing Web UI conventions (no new sanitization framework added).
